## 这份来源是什么

《FP8 Formats for Deep Learning》（arXiv 2209.05433，v1）。它定义了两种 8-bit 浮点编码 E4M3 与 E5M2 的位布局、指数偏置与可表示范围，并给出缩放（scale factor）用法与在图像/语言任务上的训练、推理证据。

它是 `foundation-number-formats` 中 FP8 部分的依据，也解释了为什么 FP8 内部还要分 E4M3 / E5M2 两种。

范围边界：**格式规范与精度研究**，不是某个量化算法的论文；主实验包含训练与推理，其中推理部分用 16-bit 训练的模型再量化为 int8 或 E4M3。

## 已读定位与阅读形式

- 阅读形式：arXiv HTML 渲染版（`arxiv.org/html/2209.05433v1`），正文与表格按 HTML 结构解析；未读 LaTeX 源码或 PDF。
- 定位：§3 的推荐用法、Table 1（各位型的最大值/最小值、指数偏置、特殊值）与"扩展动态范围"一段、§3.2 的指数偏置、§2 的缩放因子与溢出处理、§4.2 的 Table 5 推理精度。

## 关键事实

- **两种编码**（§3）：E4M3 为 4-bit 指数 + 3-bit 尾数，E5M2 为 5-bit 指数 + 2-bit 尾数；指数偏置分别为 7 与 15。
- **可表示范围**（§3，Table 1）：E4M3 最大正规值 `1.75×2^8 = 448`、最小正规值 `2^-6`、最大次正规值 `0.875×2^-6`；E5M2 最大正规值 `1.75×2^15 = 57,344`、最小正规值 `2^-14`。
- **E4M3 不表示无穷**：它让出大部分特殊值位型，只保留一种 NaN 位型，把动态范围多扩一个 2 的幂（17→18 binades，多出 256、288、320、352、384、416、448 共 7 个可表示量值）；若按 IEEE 约定则最大值只有 240。E5M2 遵循 IEEE 754，含 Inf/NaN，与 FP16 之间转换直接（§3）。
- **推荐用法**（§3）：E4M3 用于权重与激活；E5M2 用于梯度。论文说明这与既有工作一致（推理/前向用 E4M3 变体，反向梯度用 E5M2 变体）。
- **缩放**（§3.2、§2、§4.2）：偏置控制可表示范围在数轴上的位置，效果等同"每个 tensor 一个 scale factor"；论文指出存在必须按 tensor 单独调偏置的网络（§3.2）。缩放因子的选取目标设为"让 tensor 的最大幅值接近该格式的最大可表示值"，溢出默认饱和到最大可表示值，论文另说明可提供 non-saturating 模式（§2）。推理侧（Table 5，§4.2）用 per-channel 权重缩放 + per-tensor 激活缩放。

## 不能推出的结论

- 论文给的是 **FP8 格式规范与训练/推理研究**，不是某个 PTQ 算法的效果；引用它不能当作"某模型 FP8 量化必然无损"的证据。
- E4M3 的 448 与 E5M2 的 57,344 是各自的最大正规值；"FP8"本身不指定具体范围，谈范围必须说明是哪种编码。
- 论文的推理实验（Table 5）在特定模型与 per-channel/per-tensor 设置下取得，不能外推到 W4A4、KV cache 量化或任何注意力实现。
- 本页未核对其参考文献中的既有 FP8 变体，也不覆盖 FP8 在具体硬件上的 kernel 与吞吐；这些需另找部署证据。
- 本页未读 LaTeX 源码或 PDF；位布局数值按 arXiv HTML 的 Table 1 解析记录。
